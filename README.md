# Mikey Dunne – Portfolio

   Portfolio website for CS7026 Authoring for Digital Media, Assignment 1 (MSc Interactive Digital Media, Trinity College Dublin).

   **Live site:** https://mikehub001.github.io/portfolio/

   ## Structure

   - `index.html` – Home: introduction and featured projects
   - `work.html` – All projects (context, role, process, outcome)
   - `about.html` – Background, skills and interests
   - `contact.html` – Contact details and message form
   - `css/style.css` – The single external stylesheet for all pages
   - `media/` – Images and video

   ## Built with

   HTML5 and CSS3 (flexbox for the header and navigation, grid for page layouts and the project gallery, a media query for small screens).
